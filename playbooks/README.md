# Solution consulting and implementation playbooks

[Portfolio home](../README.md) · [Professional experience](../enterprise-case-studies/README.md)

These are newly authored, reusable samples showing how I would structure an engagement. They are not historical employer documents or evidence that a particular customer engagement used this exact process.

1. [Discovery questionnaire](discovery-questionnaire.md): establish the problem, constraints and acceptance criteria.
2. [60-minute solution workshop](solution-workshop-agenda.md): align stakeholders on a use case and decisions.
3. [PoC success framework](poc-success-framework.md): evaluate feasibility and business relevance with explicit exit criteria.
4. [Implementation handoff checklist](implementation-handoff-checklist.md): transfer commitments, technical context and unresolved decisions into delivery.

Each template can be adapted to a customer-facing SaaS, AI, integration or enterprise transformation engagement.
