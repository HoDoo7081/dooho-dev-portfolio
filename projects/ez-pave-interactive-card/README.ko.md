# Ez-PAVE — 인터랙티브 임상 카드뉴스 웹앱

<sub>[English](README.md) · **한국어**<br>[← 포트폴리오 홈](../../README.ko.md)</sub>

Figma로 만든 800×1280(5:8) 카드 4장을, 탭·드래그로 핵심 메시지가 드러나는 모바일 웹앱으로 구현한 프로젝트입니다. 라이브 데모: [ez-pave.lovable.app](https://ez-pave.lovable.app). 고객사 작업이라 소스와 카드 이미지는 공개하지 않습니다. 자세한 내용은 영어 원문을 참고해 주세요.

| 항목 | 내용 |
|---|---|
| 스택 | React 18 · TypeScript · Vite · Tailwind · shadcn/ui · Lovable 호스팅 |
| 핵심 결정 | 배경 선로딩 후 애니메이션(그림 → 모션 순서 보장), 5:8 비율 고정 프레임, 포인터 이벤트 기반 드래그 슬라이더, 브랜드 색 토큰화 |
| 검증 | 데스크톱·iPhone Safari·Galaxy Chrome·iPad·Galaxy Tab (제작 보고서) |
| 스스로 찾은 개선점 | 핀치 줌 차단(P1), 슬라이더 키보드·스크린리더 미지원(P1), 이미지 속 텍스트의 대체 텍스트 없음(P2), 템플릿 메타 설명 그대로(P2), 테스트 없음(P3) |
| 정직한 한계 | AI 앱 빌더로 구현했고 직접 타이핑한 코드라고 주장하지 않습니다. 도달·참여 지표는 없습니다. |
