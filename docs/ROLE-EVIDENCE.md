## Suggested reading paths

- **Recruiter, two minutes:** portfolio introduction → relevant professional case → one matching artifact.
- **Hiring manager, five minutes:** professional case → fictional engagement example → demo talk track and implementation gaps.
- **Technical reviewer:** running proof → source/tests → ADRs → AWS assumptions and limits.
